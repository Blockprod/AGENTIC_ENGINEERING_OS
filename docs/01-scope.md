# Périmètre du projet

## Ce qu'est le projet

`AGENTIC_ENGINEERING_OS` est une couche méthodologique réutilisable qui encadre
un workflow de développement logiciel dans VS Code avec Codex et Git. Il vise
un processus progressif, observable et fondé sur des preuves persistées dans le
repository.

## In scope à terme

- Règles de travail Codex.
- Rôles agentiques.
- User Stories.
- Dépendances et DAG.
- Waves d'exécution.
- Testing et review.
- Evidence.
- Certification.
- Fail-closed.
- État persistant dans le repository.

## Out of scope pour la V1

- Remplacement de VS Code.
- Remplacement de Codex.
- Développement d'un LLM.
- OpenHands.
- LangGraph.
- AutoGen.
- Microsoft Agent Framework.
- Plateforme SaaS.
- Dashboard web.
- Infrastructure distribuée.
- Orchestration multi-provider.
- Automatisation complexe prématurée.

Ces exclusions pourront être réévaluées uniquement si un besoin réel apparaît.
