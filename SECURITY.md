# Security Policy

## Supported versions

No production version is supported until the immutable `v1.0.0` release is
certified. After release, the latest `1.x` patch line receives security fixes.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, repository
contents, prompts, Evidence, or execution logs. Use the private security
reporting channel configured on the GitHub repository. Include the affected
version or commit, Windows/Python/Git versions, reproduction steps, and impact.

The maintainers will acknowledge a complete report, coordinate validation and
remediation privately, and publish an advisory when a fixed artifact is
available. No credential or secret should ever be committed to this repository.
